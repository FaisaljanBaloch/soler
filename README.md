# SolER

SolER is a Flutter-based application designed for consumers of solar energy by Renewable Energy Communities (RECs). Its purpose is to help users maximize the consumption of solar energy through insightful forecasts and intuitive features.

## Features

- **Today's Solar Forecast**:  
  Provides an hourly timeline of the solar forecast for the day, starting from the current hour and extending to the upcoming hours. This feature is horizontally scrollable and requires location permissions to determine the user's current city for tailored forecasts.

- **Language Support**:  
  SolER supports both Italian and English, offering users a seamless experience in their preferred language.

## Installation

To clone and run this application, you'll need Flutter 3.0 or newer installed on your machine. Follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/FaisaljanBaloch/soler.git
   ```

2. Navigate to the project directory:
   ```bash
   cd soler
   ```

3. Install the required dependencies:
   ```bash
   flutter pub get
   ```

4. Run the application:
   ```bash
   flutter run
   ```

## Usage

- **View the Solar Forecast**: Allow location permissions to access your current city and scroll through the hourly solar energy timeline to plan your solar energy consumption more effectively.
- **Language Settings**: Change between Italian and English in the app’s settings for a personalized experience.
